# 🌟 مدينة ديمة التعليمية — Deema Learning City

لعبة تعليمية **مجانية ومفتوحة المصدر** للأطفال بعمر ٥–٧ سنوات، صُنعت لابنة المطوّر «ديمة». تعمل في المتصفح بلا تثبيت، وتُثبَّت كتطبيق على الهاتف واللوح، وتعمل بلا إنترنت بعد أول زيارة.

## ماذا فيها؟

- **مدينة ثلاثية الأبعاد** تمشي فيها الشخصية بعصا التحكم أو بالنقر، وتقفز، وتجمع النجوم، وتدخل مبنى لكل عالم. (إن كان الجهاز ضعيفًا تتحوّل تلقائيًّا إلى خريطة ثنائية الأبعاد.)
- **٧ عوالم و٥٣ مستوى و٩٦٦ نشاطًا:**

| العالم | المحتوى |
|---|---|
| وادي الحروف | الحروف الـ٢٨ نطقًا وتتبّعًا، كلمات، حركات (فتحة/ضمّة/كسرة) |
| الرياضيات | عدّ ١–٢٠، مقارنة، جمع وطرح بالصور، أشكال، أنماط |
| العلوم | الكائنات، الحيوانات، النباتات، الجسم والحواس، الماء والهواء، الطقس، الفضاء، الغذاء والنظافة |
| الأخلاق | التحية، الصدق، الأسرة، المشاركة، البيئة، السلامة، الصبر، المدرسة والجيران + قصص قصيرة |
| الإسلامية | الله الخالق، الأذكار والآداب، النبي ﷺ والأنبياء، الصلاة والمسجد، القرآن، رمضان والأعياد، الأخلاق الإسلامية |
| English | Hello, Colors, Numbers, Animals, Food, Family, School, ABC |
| الألوان | الألوان، خلط الألوان، فرز وتذكّر |

- **١٢ نوعًا من الأنشطة:** اختيار، عدّ بالنقر، تتبّع الحرف بالإصبع، بالونات، توصيل، ذاكرة، فرز بالسحب، بناء كلمات، ترتيب، قصص بأسئلة، تلوين، رسم حر.
- **كل شيء منطوق** بصوت عربي (ar-IQ) وإنكليزي، والاعتماد على الصور والأيقونات لأن الطفل لا يقرأ بعد.
- **تكيّف ذكي:** ما أخطأ فيه الطفل يُكرَّر تلقائيًّا في الجلسات القادمة، وتلميح بعد الخطأ الثاني، والخيارات الخاطئة تخبو بعد الخطأ الثالث لئلا يعلق.
- **تحفيز:** نجوم (١–٣)، عملات، ملصق جديد بعد كل مستوى (٦ ألبومات)، هدية يومية وسلسلة أيام، متجر وخزانة في «قصر النجوم»، شخصية قابلة للتخصيص، والنجم «نجمو» يشجّع.
- **للأهل:** بوابة بسؤال حسابي، تقدّم كل عالم، نقاط الضعف، حدّ يومي للّعب مع تنبيه راحة، تصدير/استيراد التقدّم. **لا تُرسَل أي بيانات إلى أي خادم؛ كل شيء محلي.**

## التشغيل

اللعبة ملفات ثابتة بلا خطوة بناء:

```bash
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

### النشر على GitHub Pages
*Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.*
يصبح الرابط `https://<user>.github.io/deema/`.

### تطبيق أندرويد/آي أو إس (اختياري)
```bash
npm install && sh scripts/prepare-www.sh && npx cap add android && npx cap sync && npx cap open android
```

## بنية المشروع

```
index.html  sw.js  manifest.webmanifest
js/        main, engine, state, audio, ui, avatar, hub3d, screens, parent, games/*
css/style.css
data/      JSON مولَّد (فهرس + عالم لكل ملف + ui + ملصقات)
audio/     ar/ en/ مقاطع mp3 اسمها تجزئة النص
assets/emoji/  أيقونات Twemoji المستعملة فقط
tools/     مولّدات المحتوى (Python) + gen_audio.py
```

### تعديل المحتوى أو إضافته
المحتوى مكتوب بـPython في `tools/content/*.py`. بعد التعديل:
```bash
pip install edge-tts
python3 tools/build_content.py   # يعيد بناء data/ وقائمة النصوص والأيقونات
python3 tools/gen_audio.py       # يولّد المقاطع الناقصة فقط
```
(يحتاج `build_content.py` مجلّد `@twemoji/svg` من npm؛ عيّنه بالمتغيّر `TWEMOJI_DIR`.)

## الاختبار الآلي
أُضيفت وسيلة `?test=1` تسرّع الانتظار، ويعرّض `window.__cur.solve()` لحلّ النشاط الجاري. اختُبرت كل المستويات الـ٥٣ آليًّا بـPlaywright.

## ملاحظات للمراجعة
- المحتوى الإسلامي صيغ بعبارات جامعة بلا تفاصيل مذهبية، ولا يُنطق أي نص قرآني بالصوت الآلي. **يُنصح بمراجعته من أهل الاختصاص قبل النشر الواسع.**
- الأصوات مولّدة آليًّا؛ استمعوا لعيّنة منها (خصوصًا نطق الحروف المفردة والحركات) وأعيدوا توليد ما لا يعجبكم.
